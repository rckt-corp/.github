# Contributing

Open a pull request for changes and describe what changed and why. Before a
pull request can merge, its required GitHub Actions checks must pass and its
required reviews must be complete.

When the pull request is ready, use **Add to merge queue** on GitHub. The queue
runs the required checks against the proposed merge before merging it. If you
withdraw a pull request, use **Leave queue**. If its head changes, wait for the
checks and reviews required for that new revision before adding it to the queue
again.

The `apple-signing` repository has a separately documented Fastlane direct-write
exception. Follow that repository's instructions for work covered by the
exception; the merge queue remains the default for other repositories.

New repositories cannot merge pull requests until their native GitHub merge
queue is configured.
