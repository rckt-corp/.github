# rckt corp.

Building focused software products — independently.

## Products

### [Buzzy](https://github.com/rckt-corp/buzzy-app)
Credit monitoring and financial health platform. Track your credit score, report rent payments, and build better credit. Built with React Native + Expo (mobile/web) and NestJS on the backend.

### [Codea](https://github.com/rckt-corp/forge)
macOS app for managing AI agent workspaces. Run Claude Code, Cursor Agent, and Codex CLI in persistent remote workspaces — scheduled, automated, and running while you sleep.

## Tools

### [jqpoke](https://github.com/rckt-corp/jqpoke)
Self-hostable JSON manipulation tool with jq filtering and AI-assisted query generation via Ollama.

### [rckt-bot](https://github.com/rckt-corp/rckt-bot)
Orchestration engine for running Cursor agent missions headlessly via a control loop.

## Infrastructure

All services run on OVH VPS nodes in Beauharnois, QC — provisioned with Ansible, managed with Terraform.
