# rckt corp.

rckt corp. builds software products that exist mostly because someone should have built them already.

Some projects tackle real-world problems, like helping renters report payments and build their credit. Others explore better ways to build, run, and experiment with modern software.

Everything here starts with a simple idea and ends with something that runs in production.

## Products

### [Buzzy](https://joinbuzzy.com)
Credit monitoring and financial health platform. Track your credit score, report rent payments, and build better credit.

### [Codae](https://codae.app)
macOS app for managing AI agent workspaces. Run Claude Code, Cursor Agent, and Codex CLI in persistent remote workspaces — scheduled, automated, and running while you sleep.

## Tools

### [jqpoke](https://jqpoke.com)
Self-hostable JSON manipulation tool with jq filtering and AI-assisted query generation.
